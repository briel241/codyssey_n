# 미션 4 기록

- 사용한 AI 이름 / 주요 대화 캡처 파일명: ChatGPT(Codex) / 1-4gpt대화.png
- 더한 기능과 고른 이유:
  - 등급별 영화 개수 표시: 각 등급에 영화가 몇 편 있는지 한눈에 확인하기 위해 골랐다.
  - 영화 제목 검색: 영화가 많아져도 원하는 영화를 제목 일부로 쉽게 찾기 위해 골랐다.
  - 선택한 영화 삭제: 필요 없는 영화를 목록에서 간단하게 지우기 위해 골랐다.

| 받은 파일 | 맞지 않은 완성 기준 | 한 일 (고치기 / 원래 파일로 돌아가기 / 완성) |
|---|---|---|
| 영화_기능추가.html (등급별 개수 추가) | 확인된 불일치 없음. JavaScript 문법 검사만 통과했으며 실제 화면과 전체 완성 기준은 아직 확인하지 않음. | 등급·미분류 개수를 표시하도록 구현하고 기획서에 기준을 추가함. 원본은 보존함. 브라우저 확인 후 완성 여부를 판단할 예정. |
| 영화_기능추가.html (검색·삭제 추가) | 코드 동작 검사에서 확인된 불일치 없음. 브라우저에서 끌어 놓기, 파일 다시 열기, 좁은 화면은 아직 확인하지 않음. | 검색·선택·삭제·저장 데이터·검색 해제·초기화·이동·추가 로직 검사를 통과함. 검색·삭제 기준을 기획서에 추가함. 브라우저 확인은 남아 있음. |

※ 코드 동작 검사는 Node.js의 모의 DOM·저장소 환경에서 진행했다. 실제 브라우저에서 완성 기준을 모두 확인했다는 뜻은 아니다.
