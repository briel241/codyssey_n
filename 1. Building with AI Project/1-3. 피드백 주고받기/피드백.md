# 영화 티어리스트 피드백

## 잘된 점

- 등급마다 색깔이 달라서 영화가 어떤 등급에 속하는지 한눈에 구분하기 좋았습니다.
- ‘처음으로’ 기능으로 영화 목록과 배치를 처음 상태로 되돌릴 수 있어서 편리했습니다.

## 고치면 좋을 점

### 1. 영화 목록과 등급이 저장되지 않음

- **본 것:** 영화를 추가하고 등급을 정한 뒤 같은 브라우저에서 같은 파일을 다시 열었더니, 추가한 영화와 지정한 등급이 남아 있지 않았습니다.
- **기준:** 기획서의 완성 기준에 “같은 브라우저에서 같은 파일을 다시 열어도 영화와 등급이 남습니다.”라고 적혀 있습니다.
- **제안:** 영화를 추가하거나 등급을 바꿀 때 변경 사항을 브라우저에 저장하고, 파일을 다시 열면 저장된 영화 목록과 등급을 불러오도록 하면 좋겠습니다.

### 2. 같은 영화를 중복으로 추가할 수 있음

- **본 것:** 이미 목록에 있는 영화와 같은 제목을 입력하고 ‘추가’를 눌렀더니, 같은 영화 카드가 또 생겼습니다.
- **기준:** 기획서에 중복 입력을 막는 조건은 없지만, 같은 영화 카드가 여러 개 생기면 목록을 관리하기 불편하고 같은 영화에 서로 다른 등급을 지정할 수 있어 혼란스럽습니다.
- **제안:** 영화를 추가하기 전에 모든 등급과 미분류 목록에 같은 제목이 있는지 확인하고, 이미 있으면 “이미 추가된 영화입니다.”라는 안내를 보여 주면 좋겠습니다. 제목 앞뒤의 공백도 제거한 뒤 비교하면 좋겠습니다.
