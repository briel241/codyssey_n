# 미션 3 기록

| 받은 의견 | 직접 해 본 결과 | 반영 / 보류 / 되묻기 | 이유 (되묻기라면 물을 질문) |
|---|---|---|---|
| 화면 폭이 좁을 때도 내용이 잘리지 않고 보여야 한다. | 화면 폭을 좁혀 보니 오른쪽이 잘려 내용을 모두 볼 수 없었다. | 보류 | 기획서의 완성 기준에 맞지 않는 문제지만, 이번에는 영화와 등급을 저장하는 기능과 중복 카드 방지를 먼저 반영하고 화면 폭 문제는 이후 개선하기로 했다. |
| 같은 브라우저에서 같은 파일을 다시 열어도 영화와 등급이 남아야 한다. | 영화를 추가하고 등급을 정한 뒤 같은 브라우저에서 같은 파일을 다시 열었더니, 추가한 영화와 지정한 등급이 남지 않았다. | 반영 | 기획서에 명시된 완성 기준이며, 본 영화와 취향을 정리한 기록을 계속 보관할 수 있어야 한다. 영화 목록과 등급을 저장하고 다시 열 때 불러오도록 개선하기로 했다. |
| 같은 영화를 여러 번 추가하지 못하도록 하면 좋겠다. (직접 찾은 문제) | 이미 있는 영화와 같은 제목을 입력하고 ‘추가’를 누르니 같은 영화 카드가 또 생겼다. | 반영 | 같은 영화에 서로 다른 등급을 지정할 수 있어 취향을 정리할 때 혼란스럽다. 기존 영화 목록에 같은 제목이 있는지 확인하고, 중복이면 추가를 막고 안내하도록 개선하기로 했다. |

- 아무도 말하지 않았는데 내가 찾은 것: 이미 목록에 있는 영화도 같은 제목으로 다시 추가할 수 있어 중복 카드가 생긴다. 미분류 목록뿐 아니라 S·A·B·C 등급에 있는 영화까지 확인해 중복 입력을 막으면 좋겠다.

※ 표의 ‘반영’은 수정하기로 결정했다는 뜻이며, 실제 수정 완료 여부를 뜻하지 않는다.
