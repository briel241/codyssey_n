HTML은 다운로드한 뒤 브라우저에서 열어 확인합니다. 기록의 ‘반영’은 수정하기로 결정했다는 뜻이며, 실제 수정 완료를 뜻하지 않습니다.

## 작업 기록

- 화면 폭, 영화·등급 저장 등 완성 기준을 바탕으로 피드백 정리
- 저장 기능 개선 의견은 반영하기로 결정하고 좁은 화면 문제는 보류
- 직접 발견한 같은 제목의 중복 카드 문제와 개선 방향 기록
