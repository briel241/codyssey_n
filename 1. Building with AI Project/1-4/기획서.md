# 내 영화 티어리스트

## 누가 쓰나

- 나와 영화를 좋아하는 친구들

## 무엇을 하려고

- 본 영화를 S·A·B·C 등급으로 나누어 내 취향을 정리합니다.

## 화면과 동작

- 위에 S·A·B·C 칸, 아래에 아직 안 정한 영화 카드를 보여 줍니다.
- 카드를 누르고 등급 글자를 누르거나, 카드를 끌어 놓으면 해당 칸으로 옮겨집니다.
- 제목을 입력하고 ‘추가’를 누르면 아직 안 정한 영화에 카드가 생깁니다.
- 영화 목록과 등급 배치를 브라우저에 자동으로 저장합니다.
- ‘처음으로’를 누르면 처음 영화 목록과 배치로 돌아갑니다.

## 필요한 자료

- 기생충, 인터스텔라, 라라랜드, 센과 치히로의 행방불명, 어벤져스: 엔드게임, 범죄도시, 타이타닉, 토이 스토리

## 완성 기준

- 영화가 한 칸에만 있고, 옮긴 칸에 남습니다.
- 제목을 입력하면 새 영화 카드가 생깁니다.
- 같은 브라우저에서 같은 파일을 다시 열어도 영화와 등급이 남습니다.
- 화면 폭이 좁아져도 오른쪽이 잘리지 않고 내용을 볼 수 있습니다.
- ‘처음으로’를 누르면 처음 영화 8개가 모두 미분류로 돌아갑니다.
- 외부 파일·로그인·서버 실행 없이 HTML 한 장으로 열립니다.
- 빈 제목은 추가하지 않습니다.

## 더할 기능: 등급별 영화 개수 표시

- S·A·B·C 등급과 미분류에 각각 영화가 몇 편인지 표시합니다.

### 추가 완성 기준

- 처음 상태에서 S·A·B·C는 각각 0편, 미분류는 8편으로 표시됩니다.
- 카드 선택 후 등급 글자 클릭 또는 끌어 놓기로 옮기면 출발 칸과 도착 칸의 개수가 바로 바뀝니다.
- 미분류로 돌려보내도 해당 등급과 미분류 개수가 바로 바뀝니다.
- 새 영화를 추가하면 미분류 개수가 1편 늘어납니다. 빈 제목이나 중복 제목을 입력하면 개수가 바뀌지 않습니다.
- 같은 파일을 다시 열면 저장된 영화 배치에 맞는 개수가 표시됩니다.
- 처음으로를 누르면 S·A·B·C는 각각 0편, 미분류는 8편으로 돌아갑니다.
- 영화가 없는 칸에도 0편이 표시되며 좁은 화면에서도 개수가 잘리지 않습니다.
- 기존 완성 기준과 카드 선택·이동·추가·자동 저장·초기화 기능을 유지합니다.

## 더할 기능: 영화 제목 검색

- 검색창에 제목 일부를 입력하면 모든 등급과 미분류에서 일치하는 카드만 표시합니다.
- 검색 결과 개수를 표시하고, 결과가 없으면 0편으로 안내합니다.
- 검색어를 지우면 모든 카드가 원래 등급에 다시 나타납니다.
- 검색은 저장된 영화와 배치를 바꾸지 않으며 등급별 개수는 전체 영화 기준으로 유지합니다.
- 검색 중에도 카드 이동과 삭제가 가능합니다. 검색어를 바꾸면 기존 선택은 해제됩니다.
- 영화 추가와 처음으로 실행 시 검색어가 지워집니다.

## 더할 기능: 선택한 영화 삭제

- 카드를 선택한 뒤 '선택한 영화 삭제'를 누르면 선택한 영화 한 편만 삭제합니다.
- 선택한 영화가 없으면 삭제 버튼이 비활성화됩니다.
- 삭제 즉시 해당 등급의 개수와 검색 결과 개수가 갱신되고 선택이 해제됩니다.
- 삭제한 결과는 자동 저장되어 같은 파일을 다시 열어도 유지됩니다.
- 처음으로를 누르면 삭제한 기본 영화를 포함해 처음 영화 8개가 미분류로 돌아갑니다.
