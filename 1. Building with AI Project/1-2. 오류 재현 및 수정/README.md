## 작업 기록

- 제목·개봉 연도·장르 입력을 통한 영화 추가와 중복 등록 방지
- 실제 영화 수에 따른 개수 계산 및 영화·등급 배치 저장
- 보관함을 2열 × 3행으로 구성하고 6편 단위 페이지 이동 적용
- 영화 수에 관계없이 보관함 크기 유지 및 보드와 하단 정렬
- 코드·모의 환경 검사 결과 기록, 실제 브라우저 최종 확인 항목 정리
