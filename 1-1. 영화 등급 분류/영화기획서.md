# 영화 등급 분류 웹앱 기획서

## 1. 누가 쓰나

- 영화를 좋아하는 사용자가 사용한다.
- 사용자는 영화 목록을 보고 직접 **S / A / B / C 등급**으로 분류한다.
- 로그인 없이 사용할 수 있다.
- 저장할 때는 다음 중 하나를 선택한다.
  - 닉네임으로 저장
  - 익명으로 저장

> 미정: 실제 서비스 대상이 개인용인지, 여러 사람이 함께 쓰는 공개 서비스인지는 확정되지 않았다.  
> 현재는 **로컬 브라우저에서 혼자 실행하는 버전**을 기준으로 한다.

---

## 2. 무엇을 하려고

- 영화 8개를 등급별로 나누는 웹앱을 만든다.
- 사용자는 영화 카드를 드래그해서 원하는 등급 칸에 넣는다.
- 등급은 총 4단계이다.

```text
S 등급
A 등급
B 등급
C 등급
```

- 사용자가 만든 등급표를 저장할 수 있다.
- 저장된 등급표 목록을 볼 수 있다.
- 영화별 인기도 또는 순위를 볼 수 있다.
- 서버 없이 브라우저에서 바로 실행되도록 만든다.
- 데이터 저장은 우선 `localStorage`를 사용한다.

> 미정: 여러 사람의 데이터를 온라인으로 공유하는 기능은 아직 구현하지 않는다.  
> Firebase 같은 서버 저장 방식은 현재 버전에서는 사용하지 않는다.

---

## 3. 화면과 동작

### 전체 화면 구성

```text
상단 오른쪽
[저장] [순위]

왼쪽 본문
S 등급 칸
A 등급 칸
B 등급 칸
C 등급 칸

오른쪽
영화 보관함
```

### 등급 영역

- 화면 왼쪽에 S, A, B, C 등급 칸이 있다.
- 각 등급 칸은 영화 카드를 놓을 수 있는 드롭 영역이다.
- 사용자는 영화 카드를 드래그해서 원하는 등급에 넣는다.

### 영화 보관함

- 화면 오른쪽에 영화 보관함이 있다.
- 영화 보관함에는 기본 영화 8개가 표시된다.

영화 목록:

```text
기생충
인터스텔라
라라랜드
센과 치히로의 행방불명
어벤져스: 엔드게임
범죄도시
타이타닉
토이 스토리
```

- 사용자는 보관함의 영화 카드를 등급 칸으로 드래그할 수 있다.
- 필요하면 등급 칸에 있는 영화를 다시 다른 등급으로 옮길 수 있다.

### 저장 버튼

- 상단의 `저장` 버튼을 누르면 저장 모달이 열린다.
- 저장 모달에서 사용자는 다음 중 하나를 고른다.

```text
닉네임으로 저장
익명으로 저장
```

- 닉네임 저장을 선택하면 입력한 닉네임과 함께 등급표가 저장된다.
- 익명 저장을 선택하면 익명 사용자로 저장된다.
- 저장 위치는 브라우저의 `localStorage`이다.

### 순위 버튼

- 상단의 `순위` 버튼을 누르면 순위 모달이 열린다.
- 순위 모달에는 두 가지 정보가 표시된다.

```text
1. 저장된 등급표 목록
2. 영화별 인기 순위
```

### 저장된 등급표 목록

- 지금까지 저장한 등급표들이 목록으로 표시된다.
- 각 등급표에는 저장자 이름이 표시된다.
  - 닉네임 저장이면 닉네임 표시
  - 익명 저장이면 익명 사용자 표시
- 각 등급표에는 S, A, B, C 등급에 들어간 영화들이 표시된다.

### 영화별 인기 순위

- 저장된 등급표들을 기준으로 영화별 점수를 계산한다.
- 예시 점수 방식은 다음과 같이 정할 수 있다.

```text
S 등급: 4점
A 등급: 3점
B 등급: 2점
C 등급: 1점
```

- 점수가 높은 영화가 위에 표시된다.

> 미정: 점수 계산 방식은 아직 완전히 확정된 것은 아니다.  
> 위 방식은 구현을 위한 기본안이다.

## 4. 필요한 자료

### 필수 자료

#### 영화 목록

사용할 영화 8개는 확정되었다.

```text
기생충
인터스텔라
라라랜드
센과 치히로의 행방불명
어벤져스: 엔드게임
범죄도시
타이타닉
토이 스토리
```

### 포스터 이미지

- TMDB API는 사용하지 않는다.
- API 키 발급 없이 구현한다.
- 포스터 이미지는 직접 준비해서 코드에 넣는다.
- 방식은 다음 중 하나를 사용할 수 있다.

```text
1. 로컬 이미지 파일 사용
2. 직접 구한 이미지 URL 사용
```

> 미정: 각 영화의 실제 포스터 이미지 파일명 또는 이미지 URL은 아직 정해지지 않았다.  
> 따라서 구현 시에는 임시 이미지 자리 또는 직접 넣을 수 있는 구조가 필요하다.

### 저장 방식

- 서버나 외부 DB는 사용하지 않는다.
- 브라우저의 `localStorage`를 사용한다.
- 같은 브라우저에서는 저장된 등급표를 다시 볼 수 있다.
- 다른 기기나 다른 브라우저와 자동 공유되지는 않는다.

### 기술 형태

- HTML, CSS, JavaScript를 사용한다.
- 최종 형태는 브라우저에서 바로 열 수 있는 웹페이지이다.
- 외부 서버 없이 로컬에서 실행 가능해야 한다.

> 미정: 최종 파일을 단일 `.html` 파일로 만들지, `index.html`, `style.css`, `app.js`로 나눌지는 대화 중에 변경이 있었다.  
> 현재 요청은 마크다운 기획서 작성이므로 파일 구조는 확정하지 않는다.

## 5. 완성 기준

아래 기능이 동작하면 1차 완성으로 본다.

### 기본 화면

- 영화 등급표 제목이 보인다.
- S, A, B, C 등급 칸이 보인다.
- 오른쪽에 영화 보관함이 보인다.
- 영화 8개가 카드 형태로 표시된다.
- 화면 문구는 한국어로 표시된다.

### 드래그 앤 드롭

- 영화 카드를 드래그할 수 있다.
- 영화 카드를 S, A, B, C 등급 칸에 넣을 수 있다.
- 이미 배치한 영화도 다른 등급으로 이동할 수 있다.

### 저장 기능

- `저장` 버튼을 누르면 저장 창이 열린다.
- 닉네임을 입력하고 저장할 수 있다.
- 익명으로 저장할 수 있다.
- 저장한 등급표가 `localStorage`에 저장된다.

### 순위 기능

- `순위` 버튼을 누르면 순위 창이 열린다.
- 저장된 등급표 목록이 표시된다.
- 영화별 인기 순위가 표시된다.
- 저장된 데이터가 없을 때는 저장된 등급표가 없다는 안내가 표시된다.

### 로컬 실행

- 외부 서버 없이 브라우저에서 실행된다.
- Firebase나 TMDB API 없이 동작한다.
- 인터넷 연결 없이도 기본 기능이 동작해야 한다.

> 단, 이미지 URL을 외부 주소로 넣는 경우에는 인터넷 연결이 필요할 수 있다.  
> 완전한 오프라인 실행을 원하면 포스터 이미지를 로컬 파일로 준비해야 한다.
