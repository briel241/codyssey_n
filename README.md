## 과제 추가 방법

1. 해당 섹션의 과제 폴더에 결과물과 기획서를 넣습니다.
2. 필요하면 폴더 이름 뒤에 과제명을 붙입니다. 예: `1-2. 과제명`.
3. 과제 README에 작업 내용을 기록하고 위 표의 링크와 상태를 갱신합니다.
4. 새 섹션은 `3. 섹션명`처럼 폴더를 만들고 그 안에 `3-1`, `3-2` 과제를 추가합니다.

2섹션의 정식 제목과 이후 과제명은 확인되면 변경합니다. 준비 폴더는 학습을 완료했다는 의미가 아닙니다.
