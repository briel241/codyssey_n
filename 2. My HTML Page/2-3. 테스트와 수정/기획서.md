# 알록달록 나의 하루 — 디지털 다이어리

- 현재 제출용 파일: `알록달록_다이어리_v5.html`
- 개편일: 2026-11-12
- 사용자 1명의 피드백 3건을 v5에 반영: 날짜 테두리 겹침 수정, 오늘로 배치·색 변경, 기분 3개 추가. 작성자가 반영 후 재테스트에서도 의도한 대로 동작했다고 확인함.

## 대상 사용자

- 나 혼자 사용하는 개인용 다이어리다. 하루의 일과와 감정을 간단하게 남기고 지난 기록을 날짜별로 돌아보고 싶은 사람이 사용한다.

## 사용 목적

- 달력에서 날짜를 골라 그날의 일과와 기분을 기록한다.
- 종이 다이어리처럼 지난 날짜를 찾아 읽고, 필요한 내용을 수정하거나 삭제한다.
- 같은 브라우저에서 다시 열었을 때 이전 기록을 이어서 사용한다.

## 화면 구성과 동작

- 전체 분위기는 귀엽고 다채롭게 꾸민다. 밝은 배경, 서로 다른 파스텔색, 둥근 모서리와 기본 이모지를 사용하고 글자와 배경은 읽기 쉽게 구분한다.
- 위쪽에는 페이지 이름과 현재 보고 있는 연월, 이전 달·다음 달 버튼을 배치한다. 처음 열면 기기 날짜 기준 이번 달과 오늘 날짜를 선택한다.
- 달력은 일요일부터 토요일까지 7열로 구성한다. 이전 달·다음 달 버튼으로 한 달씩 이동하며 연도가 바뀌는 경우도 처리한다. 월 이동 시 해당 월 1일을 선택한다.
- 달력에서 날짜를 누르면 선택한 날짜를 강조하고, 그 날짜의 본문과 기분을 편집 영역에 표시한다. 기록이 없는 날짜는 빈 본문과 기분 미선택 상태로 표시한다.
- 넓은 화면에서는 달력과 편집 영역을 나란히, 좁은 화면에서는 달력 아래에 편집 영역을 배치한다.
- 편집 영역에는 선택한 날짜, 일기 본문 입력칸, 기분 선택 버튼, 저장 상태, 삭제 버튼을 둔다. 별도 제목 입력칸은 만들지 않는다.
- 기분은 ‘행복해요’, ‘평온해요’, ‘그저 그래요’, ‘슬퍼요’, ‘화나요’, ‘설레요’, ‘피곤해요’, ‘불안해요’의 8가지 중 하나를 고른다. 각 버튼에 이모지와 글자를 함께 표시해 색이나 그림만으로 구분하지 않는다. 좁은 화면에서는 버튼이 공간에 맞춰 줄을 바꾼다.
- 하루에 기록은 하나다. 본문이나 기분을 바꾸면 같은 날짜의 기록을 갱신하며, 새 기록을 중복 생성하지 않는다. 입력할 때마다 같은 브라우저의 로컬 저장소에 자동 저장하고 성공하면 ‘저장됨’을 표시한다.
- 본문만 쓰거나 기분만 선택해도 기록으로 저장한다. 본문이 공백뿐이고 기분도 미선택이면 새 기록을 만들지 않는다. 기존 기록을 비우려면 삭제 버튼을 사용하도록 안내한다.
- 기록이 있는 날짜에는 표시점을 붙인다. 기분을 선택한 날은 기분 이모지도 표시하고, 날짜를 누르면 기록을 다시 읽을 수 있다.
- 삭제 버튼을 누르면 확인을 요청한다. 확인하면 해당 날짜의 본문·기분과 달력의 기록 표시를 지우고, 취소하면 그대로 둔다. 기록이 없는 날짜에서는 삭제 버튼을 비활성화한다.
- 저장에 실패하면 ‘저장하지 못했어요’라고 알린다. 저장되지 않은 입력은 편집 영역에 유지하며 ‘저장됨’으로 표시하지 않는다.

- 달력 위의 연도·월·이동 버튼과 같은 줄 맨 오른쪽에 민트색 ‘오늘로’ 버튼을 둔다. 보고 있던 달과 관계없이 클릭한 시점의 오늘 날짜와 이번 달로 돌아온다. 오늘 기록이 있으면 함께 불러온다. 연도 입력이 비어 있어도 오늘로는 작동한다.
- 연도 입력칸, 월 선택칸, ‘이동’ 버튼으로 원하는 연월에 바로 이동한다. 1~9999년의 정수 연도만 허용하며 이동한 달의 1일을 선택한다. 이전·다음 달 버튼과 연월 입력값은 현재 달력에 맞춰 함께 바뀐다.
- 달력의 날짜 버튼에서 키보드 ←/→는 전날/다음 날, ↑/↓는 7일 전/후로 이동한다. 선택 날짜, 편집 내용, 달력의 연월이 함께 바뀌며 월·연도 경계와 윤년을 처리한다.
- Tab으로 달력에 들어오면 선택 날짜에 초점이 놓인다. 방향키 이동 뒤에도 새 날짜 버튼에 초점을 유지하고, Tab으로 달력 밖으로 나갈 수 있다. 본문·연도·월 입력 중 방향키는 각 입력 요소의 원래 동작을 유지한다.
- 달력 아래에 방향키 사용 안내를 표시한다. 기존 저장·기분·삭제 동작과 파스텔 디자인은 유지한다.
- 방향키로 이동한 날짜에는 선택·초점 테두리를 겹치지 않게 한 겹으로 표시한다. 키보드 초점은 조금 더 굵은 단일 테두리로 구분한다.

## 필요한 자료

- 직접 작성한 페이지 이름, 버튼 이름, 안내 문구, 기분 8가지와 테스트용 일기 문장. 출처는 본 기획서 작성자이며, 본 과제에 사용할 수 있도록 직접 작성한다.
- 기기에 설정된 날짜와 브라우저의 날짜 계산 기능으로 생성하는 월별 달력. 외부 일정 데이터는 사용하지 않는다.
- 기기 기본 글꼴과 기본 이모지를 사용한다. 별도 글꼴·아이콘 파일을 내려받거나 재배포하지 않는다.
- 사진, 외부 글, 외부 라이브러리는 사용하지 않는다. 따라서 인터넷 이미지 주소나 별도 외부 자료 사용 허가는 필요하지 않다.
- 사용자가 입력한 일기 본문과 기분. 처음에는 예시 일기 없이 시작하고 실제 개인 기록을 기본 자료에 포함하지 않는다.

## 필수 기능

- 월별 달력 표시와 이전 달·다음 달 이동
- 날짜 선택 및 해당 날짜의 기록 조회
- 본문 작성·수정과 기분 1개 선택·변경
- 날짜별 기록 삭제 및 삭제 확인
- 같은 브라우저의 로컬 저장소에 자동 저장·복원 및 저장 상태 안내
- 기록이 있는 날짜 표시와 좁은 화면에 맞춘 배치

## 완료 기준

- HTML 파일 하나를 직접 열면 다른 파일·로그인·API 키·서버 실행·인터넷 연결 없이 달력과 편집 화면을 사용할 수 있다.
- 처음 열면 기기 날짜에 맞는 이번 달과 오늘이 선택되고, 오늘의 기록이 있으면 해당 내용이 표시된다.
- 이전 달·다음 달 버튼을 누르면 연월과 날짜 배치가 함께 바뀐다. 12월에서 다음 달로 이동하면 다음 해 1월이 된다.
- 날짜를 선택하면 편집 영역의 날짜와 선택 강조가 바뀌고 그 날짜의 본문·기분만 표시된다.
- 선택한 날짜에 본문을 입력하거나 기분을 선택하면 자동 저장 후 ‘저장됨’과 달력의 기록 표시가 나타난다. 기분은 동시에 하나만 선택된다.
- 기존 본문이나 기분을 수정한 뒤 다른 날짜로 이동했다 돌아오면 수정한 값이 표시되고 같은 날짜의 기록이 중복 생성되지 않는다.
- 공백만 입력하고 기분을 고르지 않으면 새 기록 표시가 생기지 않는다. 기존 기록을 같은 상태로 비우려 하면 삭제 버튼을 사용하라는 안내가 나타난다.
- 같은 브라우저·프로필에서 같은 위치의 파일을 새로고침하거나 닫았다 다시 열면 저장한 날짜의 본문·기분과 달력 표시가 복원된다.
- 기록이 있는 날의 삭제 버튼을 누르고 취소하면 기록이 남는다. 확인하면 그 날짜의 기록과 표시가 없어지고, 다시 열어도 삭제된 상태가 유지된다. 다른 날짜의 기록은 바뀌지 않는다.
- 저장을 사용할 수 없는 환경에서는 실패 안내가 표시되고 입력 내용은 화면에 남으며, 저장 성공으로 안내하지 않는다.
- 화면 폭을 360px로 줄여도 가로 스크롤 없이 달력·본문·기분·삭제 버튼을 사용할 수 있다.

- 여러 달 이동한 뒤 ‘오늘로’를 한 번 누르면 클릭한 날의 연월·선택 날짜·편집 내용이 표시된다.
- 연도 2024와 2월을 선택해 ‘이동’을 누르면 2024년 2월과 1일이 표시된다. 연도가 비어 있거나 범위 밖이면 이동하지 않는다.
- 달력에서 ←/→는 하루, ↑/↓는 7일 이동하고 월·연도 경계에서도 편집 날짜와 키보드 초점이 선택 날짜와 일치한다. 2024년 2월 28일에서 →를 누르면 29일, 다시 →를 누르면 3월 1일이다.
- 본문에서 방향키를 눌러도 편집 날짜는 바뀌지 않는다. 날짜 이동 후 원래 날짜로 돌아오면 본문·기분이 유지된다.

- 방향키 이동 중 날짜 테두리가 한 겹으로 보이고, 360px에서도 연도·월·이동·오늘로가 한 줄에 표시된다.
- 새 기분 3개도 단일 선택·해제·날짜별 저장·복원·달력 이모지 표시에 반영된다.

## 추가 기능

- 일기 본문 검색: 검색어가 들어 있는 기록의 날짜를 찾아 이동한다.
- 월별 기분 요약: 기분별 기록 일수를 보여 준다.
- 기록을 파일로 내보내고 가져오기: 사용자가 직접 백업과 복원을 수행한다.

추가 기능은 후속 개선 후보이며 이번 필수 구현과 완료 판정에는 포함하지 않는다.

## 한계 및 비목표

1. 로그인·서버·기기 간 동기화·다른 사람과 공유·챗봇 및 AI 분석은 구현하지 않는다. 이 다이어리는 혼자 사용하는 로컬 기록 도구다.
2. 저장은 같은 브라우저·프로필과 파일 위치를 기준으로 한다. 다른 브라우저나 기기에서 기록이 이어지지 않으며, 브라우저 데이터 삭제·시크릿 모드 종료·파일 이동·브라우저의 로컬 파일 저장 제한에 따라 기록이 사라지거나 복원되지 않을 수 있다. 이번에는 백업 기능을 구현하지 않는다.
3. 하루에 본문과 기분 1개만 기록한다. 사진·첨부파일·일정 및 할 일 관리·비밀번호 잠금·기록 암호화는 제공하지 않는다. 기분 표시는 사용자 선택을 기록하며 심리 상태를 진단하지 않는다.

## 검증 방법

- **기준표와 실제 화면·저장 결과 대조:** 구현 전에 종이에 2024년 2월과 2025년 2월의 달력을 준비하고, 기기의 기본 달력과 대조해 각각 29일·28일 및 1일의 요일을 확인한다. 테스트 기록 기준표에는 ‘2024-02-28 / 산책을 했다 / 평온해요’, ‘2024-02-29 / 영화를 봤다 / 행복해요’를 적는다. 페이지에서 두 달의 날짜·요일 배치를 비교한 뒤 기준표대로 기록을 입력하고 날짜를 오가며 본문·기분·표시가 일치하는지 확인한다. 첫 기록의 본문을 ‘저녁에 산책을 했다’로 바꾸고 두 번째 기록의 삭제를 취소한 뒤 확인 삭제한다. 페이지를 닫았다 같은 브라우저에서 다시 열어 첫 기록의 수정 내용만 남는지 기준표의 예상 결과와 비교한다. 날짜·내용·기분·기록 표시가 하나라도 다르면 완료로 판단하지 않는다.
