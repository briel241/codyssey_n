# 2-3. 테스트와 수정

**알록달록 나의 하루 — 디지털 다이어리**를 테스트하고, 발견한 문제와 화면 피드백을 반영한 과제다. 2-2에서 선택한 Codex HTML을 복사해 v1부터 v5까지 저장했으며, 2-1과 2-2의 원본은 보존했다.

## 열어 볼 파일

- [알록달록_다이어리_v5.html](알록달록_다이어리_v5.html): 현재 마지막 버전이자 제출용 HTML.
- [기획서.md](기획서.md): v5 화면·동작·완료 기준에 맞춰 수정한 기획서.
- [제작검증기록.md](제작검증기록.md): 이전 두 AI 비교·테스트 3건, 수정 6건과 보조 재검증, 실제 사용자 테스트 작성란.

## 실행과 주요 기능

GitHub에서는 HTML 소스가 표시된다. 파일을 다운로드해 Chrome 또는 Edge 등의 브라우저로 열면 된다. 인터넷 연결, 로그인, 서버 실행, 별도 프로그램 설치가 필요 없다.

- 달력에서 날짜를 선택하고 본문과 기분을 자동 저장한다.
- 연도·월을 입력해 바로 이동하거나 민트색 ‘오늘로’ 버튼으로 오늘로 돌아온다.
- 날짜 버튼에 초점을 둔 뒤 ←/→로 하루씩, ↑/↓로 일주일씩 이동한다. 본문 입력 중 방향키는 글자 커서를 움직인다.
- 기분 8개 중 하나를 선택·해제하고, 날짜별 기록을 조회·수정·확인 삭제한다.
- 날짜별 기록은 같은 브라우저·프로필의 같은 파일 위치에 저장된다. 파일 이름·위치 변경이나 브라우저 데이터 삭제 시 기록이 보이지 않을 수 있다.

## 한 항목씩 수정한 버전

| 버전 | 추가한 개선 |
| --- | --- |
| v1 | 2-2codex.html 변경 없이 복사 |
| v2 | 다른 달에서 ‘오늘로’ 한 번에 돌아오기 |
| v3 | 원하는 연도·월을 골라 바로 이동하기 |
| v4 | 날짜 버튼에서 ←/→ 하루, ↑/↓ 일주일 이동하기 |
| v5 | 날짜 테두리 겹침 수정, 오늘로 버튼을 같은 줄 오른쪽으로 이동·색 변경, 기분 3개 추가(총 8개) |

각 버전은 독립 실행 HTML 전체다. 버전마다 파일 이름이 다르므로 일기 저장소도 분리된다. 실제 사용할 v5 파일의 이름과 위치를 고정해 사용한다. 폴더 이름 변경 전 저장한 기록도 새 위치로 자동 이전되지 않는다.

## 남은 테스트와 제출

코드 보조 검사로 기본 저장·복원·삭제, 날짜 이동, 기분 8개 등의 동작을 확인했다. 제작자가 보낸 화면 캡처의 날짜 테두리 겹침과 버튼 배치 요청도 v5에 반영했다. 실제 브라우저 화면 재검증과 별도 사용자 1명의 테스트는 아직 완료하지 않았다.

제출 전 제작검증기록의 수동 검사표를 확인하고, 실제 사용자 1명의 행동·피드백을 기록해 1건 이상 반영한다. 추가 피드백 반영 시 v6로 저장하고 최종 HTML·기획서·제작검증기록을 함께 갱신한다.

현재 제출용 파일은 `알록달록_다이어리_v5.html`, `기획서.md`, `제작검증기록.md`다. v1~v4는 수정 과정을 보여 주는 이력으로 보관한다.
