# 2-1. 페이지 기획서

AI의 질문에 답하며 나만의 HTML 페이지를 구체화하고, 디지털 다이어리의 기능과 완료 기준을 기획서로 정리하는 과제입니다.

| 파일 | 내용 |
| --- | --- |
| [기획서.md](기획서.md) | 제출물: 달력형 디지털 다이어리 기획서 |
| [기획서_양식.md](기획서_양식.md) | 기획서 작성용 양식 |
| [예시1.md](예시1.md) | 참고용 기획서 예시 1 |
| [예시2.md](예시2.md) | 참고용 기획서 예시 2 |

제출물은 `기획서.md` 한 파일입니다. 양식과 예시는 참고 자료이며, HTML 구현은 후속 미션에서 진행합니다.

## 작업 기록

- 혼자 하루의 일과와 감정을 기록하는 디지털 다이어리로 주제 선정
- 달력에서 날짜를 선택해 본문과 기분을 작성·수정·삭제하는 흐름 기획
- 같은 브라우저에 자동 저장하며 귀엽고 다채로운 화면으로 구성
- 대상 사용자, 사용 목적, 화면 구성과 동작, 필요한 자료, 행동별 완료 기준 작성
- 필수 기능과 추가 기능을 구분하고 한계 및 비목표 3가지, 검증 방법 1가지 명시
- 사용한 AI 서비스와 모델 이름 기록
